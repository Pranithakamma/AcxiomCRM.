## Project Overview
Acxiom CRM is a web-based Customer Relationship Management application developed using ASP.NET Core MVC and C#. It helps organizations manage customer information, sales leads, opportunities, follow-ups and business activities in one centralized platform.

## Technologies Used
- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQLite
- HTML, CSS and Bootstrap
- JavaScript
- Chart.js
- ASP.NET Core Identity

## Key Modules
- User Authentication and Authorization
- Dashboard and Reports
- Customer Management
- Lead Management
- Opportunity Management
- Follow-up and Activity Management
- User and Role Management
- Audit Logs
- REST API
- CSV Report Export

## User Roles
- Admin
- Manager
- Sales Executive

## Application Architecture
The project follows the Model-View-Controller (MVC) architecture:
- **Model:** Handles application data.
- **View:** Displays the user interface.
- **Controller:** Handles requests and application logic.

## Database
SQLite is used for data storage, and Entity Framework Core is used for database operations.

## Objective
The main objective is to improve customer relationship management, simplify sales tracking and organize business activities efficiently.
